
# AEVUM — Luxury Electric Vehicles Website

Sitio web premium para la marca ficticia AEVUM, especializada en vehículos eléctricos de lujo.

## 📁 Estructura del proyecto

```bash
AEVUM_PRODUCTION/
│
├── index.html
├── favicon.svg
├── robots.txt
├── sitemap.xml
├── site.webmanifest
│
├── css/
│   └── styles.css
│
├── js/
│   └── main.js
│
└── assets/
    └── images/
```
